# Garbage Collection

```Autohotkey
CS.GC()           ; Force full GC cycle
bytes := CS.Memory()  ; Get managed heap size

; Format nicely
mb := Round(bytes / (1024 * 1024), 2)
MsgBox('Heap: ' mb ' MB')
```

## When to Use

- Long-running scripts processing large data
- After releasing many CSProxy objects
- Before memory-intensive operations

## Note

.NET AppDomains cannot be unloaded in CLR v4. CS.GC() triggers managed GC but compiled assemblies stay in memory until process exit. The disk cache is not affected.
